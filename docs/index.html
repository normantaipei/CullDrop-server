Culldrop Support

Culldrop is an iOS and iPadOS app for photographers. Copy a memory card to your device in one pass, get on-device star ratings, cull in offline albums, and, if you run your own server, share gallery links with clients.

Get started

  1. Connect a card reader to your iPhone or iPad.
  2. In Import, tap Select Card / Folder and choose the card's DCIM folder.
  3. Choose an album. Remove the card when the app says it is safe.

The app needs no account and no server. You can also select any folder of JPG or RAW files in the Files app.

Set up a server (optional)

A server adds gallery links and off-device storage. Follow the install guide, then enter the server URL and device token in Settings → Server.

Common questions

When are photos deleted from my device?
Only after your server confirms the upload with SHA-256, and after your NAS has the file if you set one up. Offline albums are never uploaded until you tap Upload.

The app can't reach my server.
Check the full URL, including http:// or https://, and the device token. iOS requires HTTPS outside your local network.

How do I remove face data?
Go to Settings → Face Grouping → Delete Face Data.
