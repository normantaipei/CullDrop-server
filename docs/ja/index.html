Culldrop
ホームサポートプライバシー

メモリーカードからセレクトまで、iPhone や iPad で完結。

カードを丸ごとコピーし、端末上で星評価、オフラインアルバムでセレクト。ノートパソコンもアカウントも不要です。

App Store で近日公開予定です。

カードを一度でコピー

JPG、RAW の順にコピーします。ファイルはコピー時に検証され、取り外せるようになるとお知らせします。

端末上で星評価

写真にはアップロードなしで星評価とタグが付きます。連写はグループにまとめて比較できます。

オフラインアルバムでセレクト

星で閲覧し、カメラで絞り込み、低評価の写真をまとめて削除し、選んだ写真を「写真」に保存できます。

自分のサーバーで共有

任意。Culldrop Server を自分で運用すると、ギャラリーリンク、高評価優先のアップロード、NAS バックアップが使えます。

写真はあなたのもの

アカウント、広告、トラッキングはありません。開発者が写真を受け取ることはなく、AI の学習に使われることもありません。

iOS 18 以降が必要です。メモリーカードから直接取り込むには USB-C または Lightning のカードリーダーが必要です。
