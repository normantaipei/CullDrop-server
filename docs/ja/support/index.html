Culldrop サポート

Culldrop はフォトグラファー向けの iOS / iPadOS アプリです。メモリーカードを一度に端末へコピーし、端末上で星評価を行い、オフラインアルバムでセレクトできます。自分のサーバーがあれば、クライアントにギャラリーリンクを共有できます。

はじめに

  1. iPhone または iPad にカードリーダーを接続します。
  2. 「取り込み」でカード / フォルダを選択をタップし、カードの DCIM フォルダを選びます。
  3. アルバムを選びます。アプリの表示を確認してからカードを取り外してください。

アカウントもサーバーも不要です。「ファイル」App 内の JPG や RAW が入ったフォルダも選択できます。

サーバーの設定(任意)

サーバーを設置すると、ギャラリーリンクと端末外の保存先が使えます。インストールガイドに従って設置し、設定 → サーバーに URL とデバイストークンを入力してください。

よくある質問

写真はいつ端末から削除されますか?
サーバーが SHA-256 で受信を確認した後です。NAS を設定している場合は NAS の受信後です。オフラインアルバムは「アップロード」をタップするまでアップロードされません。

サーバーに接続できません。
http:// または https:// を含む URL 全体とデバイストークンを確認してください。ローカルネットワーク外では iOS が HTTPS を要求します。

顔データを削除するには?
設定 → 顔グループ → 顔データを削除 から行えます。
