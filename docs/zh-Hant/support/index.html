Culldrop 支援

Culldrop 是給攝影師用的 iOS 與 iPadOS app。一次把記憶卡抄到裝置上、在裝置上評星、在離線相簿裡挑圖；有自己的伺服器時，還能分享返圖連結給客戶。

開始使用

  1. 把讀卡機接上 iPhone 或 iPad。
  2. 在「匯入」按選取記憶卡 / 資料夾，選記憶卡的 DCIM 資料夾。
  3. 選一本相簿，等 app 提示後就能拔卡。

不需要帳號，也不需要伺服器。也可以選「檔案」App 裡任何放著 JPG 或 RAW 的資料夾。

架設伺服器（選用）

有伺服器才有返圖連結和手機以外的儲存空間。照安裝說明裝好後，在設定 → 伺服器填網址和裝置 token。

常見問題

照片什麼時候會從手機刪掉？
伺服器以 SHA-256 確認收到才會刪；有設 NAS 的話還要等 NAS 收到。離線相簿在你按「上傳」之前不會上傳。

連不上伺服器。
確認網址完整（含 http:// 或 https://）和裝置 token。iOS 在區網以外要求 HTTPS。

怎麼刪掉人臉資料？
到設定 → 人臉分組 → 刪除人臉資料。
